# skp-validator-rules

A comprehensive set of built-in validation rules and transformations for `skp-validator`.

## Features

- **String**: length, email, url, ip, uuid, phone, pattern, ascii, alphanumeric
- **Numeric**: range, multiple_of
- **Temporal**: date, date_range, age
- **Collection**: unique_items
- **Transforms**: uppercase, lowercase, trim
- **Comparison**: required, must_match, allowed_values
- **Financial**: credit_card
